# balancesample: Multivariate Balanced Data Splitting for 'rsample'

Creates training/testing splits and cross-validation folds that are
balanced on several variables at once. Numeric and categorical variables
are balanced with anticlustering, data twinning, rerandomization, or
crossed strata. Categorical variables can also be stratified exactly,
and rows from the same group can be kept together. Results are 'rsample'
objects, so they work with 'tune' and the rest of 'tidymodels'.
